# AGENTS.md

## About this repository

This is a GitHub profile repository (`walterra/walterra`). The README.md file serves as the profile page visible at https://github.com/walterra.

## Repository structure

- `README.md` - The main GitHub profile page (required)
- `AGENTS.md` - This file, instructions for AI coding agents

## Editing guidelines

### README.md content principles

- Keep the tone friendly and professional
- Use shields/badges for social links (Website, Bluesky, LinkedIn, GitHub)
- Organize content into clear sections with emoji headers:
  - 🚀 Open Source Projects
  - Contributions
  - Work history
- Include star counts and brief descriptions for projects
- Link directly to project repositories and live demos where available
- Keep project descriptions concise but informative

### Markdown formatting

- Use heading hierarchy: `#` for name, `##` for sections, `###` for subsections
- Use bullet points (`-`) for lists
- Bold project names: `**project-name**`
- Include inline code formatting for technical terms when relevant
- Keep line length reasonable for readability

## Project categories

When adding new projects to the README, categorize them appropriately:

1. **Major OSS Projects** - Personal projects with significant stars/usage
2. **Tools & Utilities** - Smaller focused tools and libraries
3. **Data Visualization** - Anything related to d3, charts, or data viz
4. **Elastic/Kibana Work** - Work-related OSS contributions
5. **Experimental/Fun** - Side projects and experiments

## Links to maintain

Ensure all links are:
- Working (no 404s)
- Using HTTPS where available
- Linking to the correct repository branches
- Pointing to live demos when they exist

## Testing

Before committing changes to README.md:
1. Preview the markdown locally or with a markdown viewer
2. Check all links are working
3. Verify badges render correctly
4. Ensure formatting is consistent
5. Check for typos and grammar

## Commit messages

Use conventional commit format:
- `docs: update profile with new project`
- `docs: fix broken link in README`
- `docs: add new social link`
- `chore: update AGENTS.md`

## Note for agents

This is a profile repository, not a code project. Focus on:
- Content accuracy and clarity
- Maintaining consistent formatting
- Keeping links up to date
- Reflecting the owner's work and interests accurately

Do not add unnecessary configuration files, CI/CD pipelines, or code linting tools unless specifically requested.
